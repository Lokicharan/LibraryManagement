📚 Book Management System

🧩 Overview

The Book Management System is a simple console-based Java application designed to manage books and users in a library.
It allows adding books and users, viewing all records, and managing book issue and return operations efficiently.

This project demonstrates Object-Oriented Programming (OOP) concepts such as Encapsulation, Abstraction, and Class Interaction.

⚙️ Features

➕ Add New Books – Register new books with title, author, and unique ID.

👤 Add Users – Create library user accounts.

📖 View All Books – Display the list of all books with their availability status.

📋 View All Users – Show all users and the number of books they have borrowed.

📕 Issue Book – Assign a book to a user (if available).

📗 Return Book – Allow a user to return a previously borrowed book.

❌ Prevents Duplicate Issuing – A book already issued cannot be borrowed by another user until returned.

🧠 Concepts Used

Classes and Objects – (Book, User, Library)

Encapsulation – Using private fields with getters and setters.

Collections Framework – Using ArrayList to store books and users.

Control Structures – Menu-driven interaction using loops and switch cases.


🖥️ How to Run the Program

Save the file as LibraryManagement.java.

Compile the program using:

javac LibraryManagement.java

Run the program:

java LibraryManagement

Use the menu options to add books, users, issue, and return books.
